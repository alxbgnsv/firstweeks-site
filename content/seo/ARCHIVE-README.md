## Политика уникальности (обязательна для всех батчей)

Три уровня работы с источниками — и наш выбор:
1. **Копипаст** — запрещён абсолютно.
2. **Рерайт чужих статей** (взять чужой текст и переформулировать) — НЕ используем: Google Helpful Content прямо понижает «lightly rewritten» контент, а структура чужой статьи остаётся чужой.
3. **Наш подход — оригинальный текст на первичных фактах:** из AAP/CDC/NIH/FDA берутся только ФАКТЫ (пороги, цифры, официальные рекомендации — они не являются объектом «уникальности»), структура/формулировки/примеры/метафоры — авторские, написаны с нуля. Источники указываются ОТКРЫТО: видимый блок Sources (rel="nofollow noopener") + поле citation в schema.org. Скрытые ссылки запрещены (hidden links = нарушение Google spam policies, риск ручных санкций).

**Процесс проверки уникальности** (выполнен для v2, обязателен для B2–B4): из каждой статьи берутся 1–2 самых характерных пассажа → точный фразовый поиск в вебе → совпадение = переписать фразу. Результат v2: проверка B1 нашла 1 фразовую коллизию (идиома «bedtime is a personal insult», гуляет по нише) — заменена на оригинальную; остальные пробы чисты. Устойчивые термины-формулы (A-B-C sleep, «100.4 °F», названия рефлексов) совпадениями не считаются — это канон, а не текст.

## Schema.org (добавлено в v2)

Каждая единица контента несёт готовый JSON-LD в поле `schema`: Article (headline, description, articleSection, author/publisher Organization, mainEntityOfPage, citation → URL первоисточников, dateModified = плейсхолдер {{BUILD_DATE}} — генератор подставляет дату сборки). Генератор сайта дополняет страницу BreadcrumbList и оборачивает FAQ в FAQPage / упражнения в HowTo по шаблонам SITE-2.
